# Nanolist

Built by the [Nano Collective](https://nanocollective.org), a community collective building AI tooling not for profit, but for the community. Nanolist is a community-curated directory of AI tools — every listing is a single JSON file reviewed by humans before it goes live, rendered as a fast, static, searchable site at [list.nanocollective.org](https://list.nanocollective.org).

Visitors make zero third-party requests: search runs in the browser, icons are self-hosted, and there is no analytics.
